# Chatbot

一个 macOS 上的 AI 聊天助手，目标是**随手就能叫出来**：一个快捷键唤起，问完就走，不打断手头的事。

## 为什么做这个

现在用 AI 的流程太碎了：切浏览器 → 打开网页 → 粘贴内容 → 等回答 → 切回来。屏幕上的东西（报错信息、图表、一段代码、一个弹窗）反而要手动描述或者截图再上传。

这个 app 想解决的就是这段摩擦：**看到什么就直接问什么**。

## v1.0 功能范围

### 1. 截图问答

- 全局快捷键唤起，框选屏幕上任意区域，直接对选区提问
- 支持整屏 / 单个窗口 / 自由框选
- 典型用法：
  - 框住一段报错 → "这是什么问题，怎么修"
  - 框住一张图表 → "这张图说明了什么"
  - 框住一段外文 → "翻译并解释"
- 截图内容随消息一起发给模型，不需要手动保存文件

### 2. 联网问答

- 模型可以主动搜索网页，回答里带信息来源链接
- 用于时效性问题：最新版本号、近期事件、某个库现在的 API 长什么样
- 拿不准的答案应该明确说"没查到"或者给出链接让人自己核对，而不是编一个

### 3. 快速调用（贯穿上面两点的基础体验）

- 全局快捷键从任何 app 里直接唤起，不需要先切到 Chatbot
- 轻量窗口：问完即走，不需要管理会话列表也不会有心理负担
- 常驻但安静——不抢焦点、不弹通知

## v1.0 明确不做

划清楚边界，避免一上来铺太大：

- 不做多轮长对话管理和历史记录归档
- 不做团队协作 / 分享
- 不做插件系统或自定义工作流
- 不做移动端 / 跨平台

## 技术栈

**待定。** 候选方向：

- 原生 SwiftUI——系统集成（全局快捷键、屏幕录制权限、菜单栏）最顺，体积和启动速度也最好
- Electron / Tauri——跨平台，但截图和全局快捷键要额外处理系统权限

选型确定后会补充到这里。

## AI 后端

用 **DeepSeek** 提供对话能力。

需要注意：DeepSeek 的 API 主要提供对话补全（OpenAI 兼容格式），**联网搜索需要在 app 侧自己实现**——大致是接一个搜索 API 拿到结果，再把网页内容作为上下文喂给模型。这块的具体方案待定。

API key 的存放方式（Keychain / 环境变量 / 设置页）也待定。
