# Chatbot v1 功能规格

> 本文汇总了 Wayfinder 地图 #1 下各 ticket 的结论，是 v1 实现的依据。术语以 [`CONTEXT.md`](../CONTEXT.md) 为准，实现方案见 [`ARCHITECTURE.md`](ARCHITECTURE.md)，关键决策的取舍见 [`docs/adr/`](adr/)。
>
> 产品定位：**快速解决问题**。用一个快捷键唤起，问完就走。复杂问题用户会去别的工具里解决，所以 v1 不开模型思考、不做重量级的会话管理，也不重复实现外部工具已经做得很好的事（比如截图）。

## 1. 形态

- 菜单栏常驻。平时只在菜单栏，不出现在 Dock 里；设置窗口或主窗口打开时，临时出现在 Dock 和 ⌘Tab 里，方便被别的窗口盖住后切回来，这类窗口全部关掉后恢复成只在菜单栏。Quick Panel 不会让 Dock 出现图标。
- 设置窗口和主窗口是普通窗口：点别的 app 后它们留在原处，不会自动隐藏。
- 三个界面：
  - **Quick Panel**：按 Hotkey 唤起的浮动面板，用来提问。
  - **Main Window**：浏览历史 Conversation。
  - **设置窗口**：标准的 macOS 设置窗口，用 cmd+, 打开。
- 菜单栏图标的菜单：打开主窗口、设置、退出。
- 界面语言有中文和英文两种，跟随系统。
- 最低支持 macOS 26 Tahoe。

## 2. Hotkey 与 Quick Panel

### 2.1 Hotkey
- 默认 **option+space**，可以在设置里修改。
- 不需要任何系统权限。
- 首次启动和改键时检测和**系统快捷键**的冲突，冲突时给出提示。
- 和其他 app 的冲突检测不到（ChatGPT 桌面版默认也用 option+space），只在设置里 Hotkey 旁边放一句静态提示：按了没反应时，可能和 ChatGPT 等 app 冲突，请换一个组合。

### 2.2 外观（以 #15 原型的「聊天窗式」为准）
原型：https://linem7.github.io/Chatbot/ （源在 `gh-pages` 分支）

- 出现在**鼠标所在屏幕的偏上居中**位置。宽度固定，高度也固定（约 560pt，最多占屏幕高度的 70%），不能拖动。
- 能显示在全屏 app 上方，也能在所有桌面空间里出现。
- 风格：macOS 原生的半透明材质，大圆角，扁平简洁。
- 布局从上到下：
  1. **顶栏**：左边是模型选择器（显示「Connection / Model」），中间是 Conversation 标题，右边是「新对话」和「在主窗口中打开」两个按钮。
  2. **消息区**：用户消息是靠右的气泡，回答靠左，没有气泡。
  3. **输入区**：
     - 附件缩略图条：图片显示缩略图，文件显示图标和文件名，每个都有 × 可以删除；
     - 多行输入框；
     - 工具行：「+」、地球按钮（联网搜索）、「⏎ 发送 · ⇧⏎ 换行」提示、发送 / 停止按钮。
- 还没有消息时，显示一个空状态，提示可以粘贴截图或拖入文件。

### 2.3 唤起、隐藏和后台生成
- 唤起时，如果距离上次 Turn 结束**不到 10 分钟**，就接着上一个 Conversation，否则新开一个。10 分钟是固定的，不能设置。
- 如果后台还有回答在生成，唤起时一律接着那个 Conversation。
- 以下三种操作都会**隐藏**面板：
  - 再按一次 Hotkey；
  - 按 Esc（Esc 只负责隐藏，不会停止生成）；
  - 失焦，也就是点击了面板外面。
- 面板隐藏后，**回答在后台继续生成**。
- 停止生成：点停止按钮，或按 cmd+.。
- 菜单栏图标的提示：
  - 生成中显示动画；
  - 生成完但还没看时显示一个小圆点，下次打开面板后消失。
  - 不发系统通知。

### 2.4 快捷键（面板内）

| 按键 | 作用 |
|---|---|
| ⏎ | 发送（输入法正在组字时不发送） |
| ⇧⏎ | 换行 |
| ⌘N | 新对话。正在生成时，先停止当前回答（保留为 Interrupted），再新开 |
| ⌘. | 停止生成 |
| Esc | 隐藏面板 |

## 3. Model 与 Conversation

- **Conversation 创建时选定 Model，之后不能再换。** 新 Conversation 默认使用 Default Model。
- 模型选择器：
  - Conversation 还没有消息时，切换会直接改掉它的 Model；
  - 已经有消息时，切换的结果是用新 Model **开一个新 Conversation**。如果正在生成，和 ⌘N 一样先停止当前回答（保留为 Interrupted），再新开。
- 模型选择器按 Connection 分组列出 Model，并标注能力（图片、联网）。
- **不开模型思考，也不展示推理过程**（ADR-0002）。
- **Retry**：只有最后一条回答处于 Interrupted 或出错状态时才能重试，新回答会替换旧的。没有「重新生成任意一条」，也不能编辑旧消息。
- system prompt：由 app 内置一份默认的，用户可以在设置里全局修改，也可以恢复默认。默认内容要求模型：
  - 拿不准就明确说没查到或不确定，不要编造；
  - 联网搜索时引用来源。

  当前日期不在可编辑的文本里：发送时由 app 在 system prompt 最前面加一行当前日期，所以用户改了 prompt 也不会把日期弄丢。

## 4. Attachment（附件）

- **支持的类型**：
  - 图片：PNG / JPEG / GIF / WebP / HEIC；
  - PDF；
  - 纯文本和代码文件：txt、md、csv、json、各种源代码等。是否算文本文件按内容判断，能按文本解码的都收下。
- 其他类型一律拒绝，并提示「不支持这种文件类型」。
- **入口**：「+」、粘贴、拖拽，三者按同一套规则处理。
  - 粘贴可以是剪贴板里的图片数据，也可以是 Finder 中复制的文件。粘贴纯文字时照常进入输入框。
  - v1 **没有内置截图**。用户用其他工具截好图后粘贴进来，这就是图片输入的主要方式。
- **当前 Model 不支持图片时**，忽略图片并提示「当前模型不能接受图片」。能否接受图片以 Model Capabilities 为准。
- **PDF 一律在本地抽取文本**，作为文字发给模型。抽不出文字（扫描版）时给出提示。
- **数量和大小不限制**。图片在发送前自动缩到长边 2000px。上下文超长时由模型报错，处理方式见 §7。
- 历史中保存附件**副本**：图片存压缩后的版本，PDF 和文本文件存抽出的文字。副本随 Conversation 一起删除。

## 5. Web Search（联网搜索）

- **只用 Provider 的原生搜索**，不接外部搜索服务（ADR-0003）：
  - Anthropic 的 `web_search` 工具；
  - Gemini 的 `google_search`；
  - OpenAI 兼容 Provider（**包括 DeepSeek**）在 v1 不支持搜索。
- 「是否支持 Web Search」是 Model Capabilities 的一项。
- **默认开启**，由模型自己决定搜不搜。
- 地球按钮可以对**当前 Conversation** 关闭搜索。Model 不支持搜索时，按钮置灰，悬停提示「当前模型不支持联网」。
- 每次 Turn 最多搜索 3 次。这个上限只对 Anthropic 有效，Gemini 无法限制。
- 显示方式：
  - 搜索中显示「正在搜索：关键词」，正文开始输出后，变成一行灰字「搜索了：A、B」。
  - **Citation** 在正文中显示为角标 [1][2]；回答末尾列出「标题 + 域名」，点击后用默认浏览器打开。
  - 用 Gemini 时，按其条款要求，在回答下方原样展示 Google 的「搜索建议」组件。

## 6. 回答的显示

- 渲染**完整 GFM**：标题、列表、表格、引用、链接、行内代码。代码块有语法高亮，悬停时出现「复制」按钮。不支持 LaTeX 公式，公式按原文显示。
- 流式输出，边生成边渲染。
- 鼠标悬停在回答上时，出现「复制」按钮，复制整条回答的 Markdown 原文。

## 7. 错误与中断

- **用户取消不算错误**：已经收到的部分保留，回答标为 Interrupted，显示「已中断」，如果是最后一条，还会显示「重试」。
- **出错时**，错误直接显示在这条回答的位置，已经生成的部分保留，并按类别给出下一步：

| 错误类别 | 显示 | 操作 |
|---|---|---|
| `authentication`（key 无效或缺失） | key 无效或已过期 | 打开设置 / 重试 |
| `rateLimited`（限流或额度用完） | 请求太频繁或额度用完，如果接口给了等待时间就一起显示 | 重试 |
| `overloaded`（服务端过载、5xx） | 服务暂时不可用 | 重试 |
| `network`（断网、超时） | 网络连接失败 | 重试 |
| `contextTooLong` | 对话太长了 | 新对话 |
| `unsupportedInput` | 当前模型不支持这种输入 | 无 |
| `invalidRequest` / `providerError` | 显示接口返回的原始信息 | 重试 |

- **不自动重试**。
- **上下文不截断**：每次都把完整历史发给模型，超长时按上表的 `contextTooLong` 处理。

## 8. 历史（Main Window）

- 列表按最后一条消息的时间倒序排列。
- **全文搜索**，范围包括标题和所有消息正文。
- 点开一个 Conversation 可以查看完整内容，也可以继续对话。在 Main Window 的详情里点「在 Quick Panel 中继续」，或者双击列表项，会把这个 Conversation 装进 Quick Panel 并弹出，然后在面板里继续对话。如果 Quick Panel 里正有别的 Conversation 在生成，按 ⌘N 的规则先停止当前回答（保留为 Interrupted），再装入；选中的正是正在生成的那个时，直接弹出面板，不停止生成。
- **标题**：第一次 Turn 结束后，由这个 Conversation 的 Model 在后台生成一次。生成之前或生成失败时，用第一条用户消息的前一行代替。
- **删除**：
  - 右键或按 ⌫ 删除单个 Conversation，不弹确认；
  - 设置里的「清空全部历史」需要二次确认。
- **自动清理**：app 启动时检查一次，之后每天检查一次，**静默删除最后一条消息在 30 天前的 Conversation**，连同它的附件。不提示，也没有保留机制。
- **保存时机**：
  - 用户消息发出后立即保存；
  - 回答在 Turn 结束、被取消、出错或 app 退出时保存。退出时已经生成的部分以 Interrupted 状态保存。
- **不做导出**。

## 9. 设置

设置是独立窗口，分三个标签页：

**通用**
- Hotkey 改键（附带冲突检测）
- Default Model
- 开机启动（默认开启）

**Connection**
- 增加、编辑、删除 Connection。
- 添加时先选模板：DeepSeek / Anthropic / Gemini / OpenAI / 自定义。模板会自动填好 Provider 和 base URL，用户只需要粘贴 API key。自定义模板可以选 Provider，自己填 base URL。
- 保存时自动拉取 Model 列表，这一步同时就是连接测试。失败时按 §7 的错误类别显示原因。
- 可以隐藏不用的 Model。拉取失败时可以手动填写模型 ID。
- **不能手动修改 Model Capabilities**。
- 删除 Connection 时，**用它的 Conversation 会一起删除**，删除前弹窗确认。如果 Default Model 属于这个 Connection，会要求重新选择。

**高级**
- 编辑 system prompt，可以恢复默认。
- 清空全部历史。

## 10. 首次启动

- 自动打开设置窗口的 Connection 页，并预选 DeepSeek 模板。
- 检测 Hotkey 冲突并给出提示。
- 如果还没有任何 Connection 就按了 Hotkey，面板里只显示一个「添加 Connection」按钮。
- v1 不需要任何系统权限：没有屏幕录制，也没有辅助功能。

## 11. 分发与更新

- **v1 只自用**：在本机用 Xcode 构建、打包，再安装。用自签名证书签名，不做公证（ADR-0005）。
- **不做更新检查，也不在 GitHub Release 上发布**。以后要分发给别人时，再加上 tag 自动发布和「有新版本」提示（仓库已经是公开的）。届时用户第一次打开时，需要到「系统设置 → 隐私与安全性」里点「仍要打开」。

## 12. v1 明确不做

- 内置截图（用户用其他工具截图后粘贴）
- 外部搜索服务；DeepSeek 因此不联网
- 模型思考和推理展示
- 会话中途换模型、编辑旧消息、重新生成任意一条回答
- 上下文截断或摘要
- token 用量统计
- 导出 Conversation
- 手动覆盖 Model Capabilities
- LaTeX 公式渲染
- 对外分发：GitHub Release 发布、更新检查、自动更新
- Mac App Store 分发、App Sandbox
- 跨平台和移动端、插件系统、团队协作、iCloud 同步
