# Chatbot v1.0.3

补丁版本：**Quick Panel 发送问题后将问题移到消息区最上面，回答生成时保持阅读位置**。

## 下载

- **系统要求：macOS 26 或以上，Apple Silicon（M 系列芯片）。不提供 Intel 安装包。**
- [下载 Chatbot-1.0.3-macOS-arm64.zip](https://github.com/linem7/Chatbot/releases/download/v1.0.3/Chatbot-1.0.3-macOS-arm64.zip)
- [完整安装指引](https://github.com/linem7/Chatbot/blob/v1.0.3/docs/INSTALL.md)
- Assets 中另附 SHA-256 校验文件；GitHub 的 Source code 是源码，不是安装包。
- 从旧版升级：退出 Chatbot 后用新版替换 Applications 里的 `Chatbot.app`。设置、API key 和本地历史都会保留。

## 本版改动

- 发送问题后，用户 Message 移到消息区最上面，回答在下方生成；视图不再跟着回答自动滚到底部。
- 回答较短时下方留白；回答超出一屏时，可以手动向下滚动阅读。
- Retry 同样跳回对应问题；打开或装回已有 Conversation 时仍停在底部。
- 改动见 [PR #73](https://github.com/linem7/Chatbot/pull/73)，问题记录见 [#72](https://github.com/linem7/Chatbot/issues/72)。

## 验证与安装

- 用户已在 Mac 上安装并确认本次交互改动测试通过。
- 发布包在 Mac 上构建，核验版本号、Apple Silicon 架构、签名和 SHA-256 摘要。
- 应用沿用固定自签名证书，未经过 Apple 公证。首次安装的放行步骤见 [安装指引](https://github.com/linem7/Chatbot/blob/v1.0.3/docs/INSTALL.md)。
- 其余功能沿用 [v1.0.2](https://github.com/linem7/Chatbot/releases/tag/v1.0.2)。

遇到问题可在 [GitHub Issues](https://github.com/linem7/Chatbot/issues) 提交系统版本和复现步骤，请勿公开 API key。
