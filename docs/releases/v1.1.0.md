# Chatbot v1.1.0

改善 Quick Panel 的阅读体验：**首轮回答不再自动滚到底部，用户问题上方统一保留适当间距**。

## 下载

- **系统要求：macOS 26 或以上，Apple Silicon（M 系列芯片）。不提供 Intel 安装包。**
- [下载 Chatbot-1.1.0-macOS-arm64.zip](https://github.com/linem7/Chatbot/releases/download/v1.1.0/Chatbot-1.1.0-macOS-arm64.zip)
- [完整安装指引](https://github.com/linem7/Chatbot/blob/v1.1.0/docs/INSTALL.md)
- Assets 中另附 SHA-256 校验文件；GitHub 的 Source code 是源码，不是安装包。
- 从旧版升级：退出 Chatbot 后用新版替换 Applications 里的 `Chatbot.app`。设置、API key 和本地历史都会保留。

## 本版改动

- 修复新 Conversation 的首轮回答仍随着生成结果自动滚到底部的问题。从第一轮开始，发送后即定位到用户 Message，回答变长时保持阅读位置。
- 用户 Message 与消息区顶部统一保留 20pt 间距，首轮、后续轮次和 Retry 一致。
- 回答较短时下方仍留白；可以手动滚动阅读回答，打开或装回已有 Conversation 时仍停在底部。
- 改动见 [PR #76](https://github.com/linem7/Chatbot/pull/76)，问题记录见 [#74](https://github.com/linem7/Chatbot/issues/74)、[#75](https://github.com/linem7/Chatbot/issues/75)。

## 验证与安装

- 用户已通过 `scripts/install.sh` 在 Mac 上安装并确认本次交互改动测试通过。
- 本地 Debug / Release 构建通过；独立 SwiftUI 窗口的 13 项布局检查通过，覆盖首轮流式增长、第二轮、Retry 和恢复历史。
- 发布包在 Mac 上构建，核验版本号、Apple Silicon 架构、签名和 SHA-256 摘要。
- 应用沿用固定自签名证书，未经过 Apple 公证。首次安装的放行步骤见 [安装指引](https://github.com/linem7/Chatbot/blob/v1.1.0/docs/INSTALL.md)。
- 其余功能沿用 [v1.0.3](https://github.com/linem7/Chatbot/releases/tag/v1.0.3)。

遇到问题可在 [GitHub Issues](https://github.com/linem7/Chatbot/issues) 提交系统版本和复现步骤，请勿公开 API key。
