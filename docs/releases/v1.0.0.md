# Chatbot v1.0.0

首个可下载安装的版本：macOS 菜单栏 AI 聊天助手，支持快捷键唤起、图片和文件、多服务商模型，以及本地对话历史。

## 下载

- **系统要求：macOS 26 或以上，Apple Silicon（M 系列芯片）。不提供 Intel 安装包。**
- [下载 Chatbot-1.0.0-macOS-arm64.zip](https://github.com/linem7/Chatbot/releases/download/v1.0.0/Chatbot-1.0.0-macOS-arm64.zip)
- [完整安装指引](https://github.com/linem7/Chatbot/blob/v1.0.0/docs/INSTALL.md)
- Assets 中另附 SHA-256 校验文件；GitHub 的 Source code 是源码，不是安装包。

## 安装与首次使用

1. 下载并解压 ZIP，将 `Chatbot.app` 拖进 **Applications** 后打开。
2. 本版本使用自签名证书，未经过 Apple 公证。首次打开如被拦截，确认下载来源后进入 **System Settings › Privacy & Security › Open Anyway**，再确认 **Open**。不需要自行创建或安装证书。
3. 在 **Settings › Connections** 选择服务商，输入自己的 API key，点 **Save**。默认提供 DeepSeek 模板；其他服务可通过 **+** 添加。
4. 在 **Settings › General › Default Model** 选择模型，按 **Option + Space** 开始聊天。

应用平时显示在菜单栏，首次启动默认开启 **Launch at Login**，可在 Settings 关闭。使用模型需要自己的 API key 和额度。

## 本版功能

- Quick Panel：Option + Space 唤起，可改用连按两次 ⌘；支持固定在最前和拖动位置。
- 流式回答、Markdown、代码高亮和复制。
- 粘贴截图，或添加图片、PDF、文本和代码文件。
- OpenAI 兼容、Anthropic、Gemini 协议；包含 DeepSeek、OpenAI、OpenRouter、Alibaba Cloud Model Studio 等连接模板。
- 支持的模型可使用服务商原生联网能力；图片、搜索和引用能力依模型及平台而定。
- 本地对话历史和全文搜索；API key 存在 macOS Keychain。
- 中文和英文界面，跟随系统语言。

## 使用说明与限制

- 连按两次 ⌘ 需要 **Accessibility** 权限；默认 Option + Space 不需要该权限。
- 固定面板后，Esc、快捷键和失焦都不会收起它，需要先取消图钉固定。
- 超过 30 天没有新消息的对话会自动清理。
- 不包含内置截图、自动更新或更新检查。升级时退出 Chatbot，下载新版替换 Applications 中的应用；本地设置、API key 和历史保留。
- 本次发布完成 Release 构建和打包，未追加发布前测试或其他设备试装。

遇到问题可在 [GitHub Issues](https://github.com/linem7/Chatbot/issues) 提交系统版本和复现步骤，请勿公开 API key。
