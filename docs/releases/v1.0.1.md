# Chatbot v1.0.1

补丁版本：**联网搜索改为默认关闭**，需要时再打开；设置里新增「新对话默认联网」开关。

## 下载

- **系统要求：macOS 26 或以上，Apple Silicon（M 系列芯片）。不提供 Intel 安装包。**
- [下载 Chatbot-1.0.1-macOS-arm64.zip](https://github.com/linem7/Chatbot/releases/download/v1.0.1/Chatbot-1.0.1-macOS-arm64.zip)
- [完整安装指引](https://github.com/linem7/Chatbot/blob/v1.0.1/docs/INSTALL.md)
- Assets 中另附 SHA-256 校验文件；GitHub 的 Source code 是源码，不是安装包。
- 从 v1.0.0 升级：退出 Chatbot 后用新版替换 Applications 里的 `Chatbot.app`。设置、API key 和本地历史都会保留。

## 本版改动

- **联网搜索默认关闭**：新建的对话，地球按钮是关的，请求不带搜索。想联网就点一下地球按钮，只对当前这段对话有效。
- **新增「Search the Web in New Conversations」开关**，在 **Settings › General** 的 Default Model 下面。打开后，新建的对话默认就是联网状态。
- 每个新对话都按这个设置开始，不记住上一段对话的选择；已经保存的对话保持各自原来的状态，不迁移。

## 其他

- 其余功能和界面与 v1.0.0 相同，详见 [v1.0.0 说明](https://github.com/linem7/Chatbot/blob/v1.0.0/docs/releases/v1.0.0.md)。
- 安装、快捷键、权限、升级和卸载见 [安装指引](https://github.com/linem7/Chatbot/blob/v1.0.1/docs/INSTALL.md)。

本版完成了 Release 构建、打包，并装到本机启动确认。
