# Chatbot v1.0.2

补丁版本：**修复百炼视觉模型被误判为不支持图片输入的问题**。

## 下载

- **系统要求：macOS 26 或以上，Apple Silicon（M 系列芯片）。不提供 Intel 安装包。**
- [下载 Chatbot-1.0.2-macOS-arm64.zip](https://github.com/linem7/Chatbot/releases/download/v1.0.2/Chatbot-1.0.2-macOS-arm64.zip)
- [完整安装指引](https://github.com/linem7/Chatbot/blob/v1.0.2/docs/INSTALL.md)
- Assets 中另附 SHA-256 校验文件；GitHub 的 Source code 是源码，不是安装包。
- 从旧版升级：退出 Chatbot 后用新版替换 Applications 里的 `Chatbot.app`。设置、API key 和本地历史都会保留。

## 本版改动

- 百炼的 OpenAI 兼容接口未报告图片能力时，按内置模型表判断，修复 `qwen3.8-max` 等视觉模型无法添加图片的问题。
- 已保存的百炼 Connection 会在运行时补上图片能力，无需删除连接或重新拉取模型列表。
- 未命中内置表的模型仍按保守默认处理，避免把纯文本模型误判为支持图片。
- 修复见 [PR #71](https://github.com/linem7/Chatbot/pull/71)，问题记录见 [#70](https://github.com/linem7/Chatbot/issues/70)。

## 验证与安装

- 修复通过 GitHub CI 构建和核心测试，并在用户的 Mac 上完成 Release 安装及百炼 `qwen3.8-max` 图片输入验证。
- 应用沿用固定自签名证书，未经过 Apple 公证。首次安装的放行步骤见 [安装指引](https://github.com/linem7/Chatbot/blob/v1.0.2/docs/INSTALL.md)。
- 联网搜索仍默认关闭；其余功能沿用 [v1.0.1](https://github.com/linem7/Chatbot/releases/tag/v1.0.1)。

遇到问题可在 [GitHub Issues](https://github.com/linem7/Chatbot/issues) 提交系统版本和复现步骤，请勿公开 API key。
